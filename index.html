~/operators/nifi-operatorReleased v1.0.0 · Oct 2026

  

   

    
NiFi Kubernetes Operator
Go · Kubebuilder · CRDs · admission webhooks · CSI

   

   
An in-house alternative to NiFiKop and Stackable that I took from scoping to a v1.0.0 release in about eight weeks. Declare a NiFiCluster resource and the operator builds the cluster and keeps it in the state you asked for.

   


# illustrative spec
kind: NiFiCluster
metadata:
  name: analytics
spec:
  nodeGroups:
    - name: main
      replicas: 3
  coordination: kubernetes  # or zookeeper
  tls:
    perPodCerts: true     # custom CSI driver
  auth: oidc               # mTLS · LDAP · single-user
  disruptionBudget: true

    

     
Features

     
    
      
  • Multiple node groups and scaling
    • 
      
  • Embedded ZooKeeper or NiFi 2.x Kubernetes leader election
    • 
      
  • Per-cluster CA, per-pod certificates through a custom CSI driver
    • 
      
  • mTLS, single-user auth, OIDC and LDAP
    • 
      
  • PDBs, graceful decommission on preStop, drift self-heal
    • 
      
  • Admission webhook with 38 validation tests
    • 
      
  • Helm chart, OpenShift SCC / restricted-v2 support
